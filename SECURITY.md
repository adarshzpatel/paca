# Security

Paca talks to herdr over a local Unix socket and, for remote machines, over SSH
with your existing keys. Bugs in either path can matter, so please report them
privately.

## Reporting

Use [GitHub private vulnerability reporting](https://github.com/adarshzpatel/paca/security/advisories/new).
Don't open a public issue for a security bug.

Include the Paca version or commit, your macOS version, and steps to reproduce.
Expect a first reply within a week.

## Supported versions

Paca is pre-1.0. Only the latest commit on `main` gets fixes.
