# Name and logo

The code in this repository is MIT licensed. The Paca name, the alpaca symbol,
the mascot artwork, the wordmark and the app icon are not. They identify this
project, and they stay with it.

What that means in practice:

- You can build, run and modify Paca, and ship your own builds for personal use
  or inside your company, with the logo intact.
- You can use the name and logo to talk about Paca: blog posts, talks, videos,
  links back here.
- If you distribute a fork to other people, give it a different name and icon.
  Users should be able to tell your build from this one.
- Don't use the logo or mascot in a way that suggests this project endorses you.

The artwork lives in `brand/` and `Sources/Paca/Resources/` (the `paca-*` files
and `Paca.icns`). The fonts in `brand/fonts/` are under the SIL Open Font
License, and the icons listed in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)
keep their own licenses.

Not sure whether something is fine? Open an issue and ask.
